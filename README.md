## Generous Wood Recipes

A small quality-of-life data pack that fixes vanilla's stingiest wood recipes. No more spending 6 planks on 2 trapdoors.

- **Minecraft Java Edition 26.3** (data pack format 121)
- Works on **existing worlds** and servers, no mods needed
- Covers **all 13 wood types**: Oak, Spruce, Birch, Jungle, Acacia, Dark Oak, Mangrove, Cherry, Pale Oak, Poplar, Bamboo, Crimson and Warped
- Changes **recipe output amounts only**. Patterns and ingredients are exactly vanilla's, so nothing new to learn

---

## What changes

Amounts are **per craft**.

### Building

| Item | Vanilla | This pack |
|---|---:|---:|
| Trapdoor | 2 | **8** |
| Door | 3 | **12** |
| Fence | 3 | **6** |
| Fence gate | 1 | **4** |
| Stairs | 4 | **8** |
| Bamboo mosaic stairs | 4 | **8** |
| Sign | 3 | **12** |
| Hanging sign | 6 | **18** |
| Shelf | 6 | **18** |
| Wood / stripped wood blocks | 3 | **4** |

### Utility

| Item | Vanilla | This pack |
|---|---:|---:|
| Stick | 4 | **8** |
| Button | 1 | **4** |
| Pressure plate | 1 | **2** |
| Chest | 1 | **4** |
| Barrel | 1 | **4** |
| Chiseled bookshelf | 1 | **4** |
| Note block | 1 | **4** |
| Bowl | 4 | **8** |
| Ladder | 3 | **2** |

**Unchanged:** slabs (already 6 for 3 planks), boats, planks from logs, jukeboxes, crafting tables, and every recipe not listed above.

> **Why do ladders go down?** Ladders are made only from sticks, and sticks now go twice as far. Crafting ladders at the old rate would count the bonus twice. Per log of wood you still get more ladders than in vanilla.

## How the numbers were chosen

1. **Block volume.** Slabs and stairs in vanilla already match the wood you put in, so they are the reference. Bigger or thinner pieces are scaled from that.
2. **No double-counting.** Recipes that use sticks (ladders, fences, gates, signs) were adjusted for the stick buff instead of stacking another bonus on top.
3. **A fuel cap.** Wood items can be burned in furnaces, so a bigger yield means more fuel. Every recipe chain was checked so that **one log never burns longer than vanilla charcoal made from the same log (1,600 ticks)**. The pack can't out-fuel vanilla.

The only change outside recipes is **hanging sign burn time, 800 → 500 ticks**, which keeps 18-per-craft hanging signs under that cap. Nothing else in the game burns differently.

## Installation

1. Download `generous_wood.zip`.
2. Put it in your world's `datapacks` folder (`saves/<world name>/datapacks`; on a server, `world/datapacks`).
3. Run `/reload` in game, or reopen the world. `/datapack list` should show the pack as enabled.

To remove it, delete the zip. Items you already crafted stay in your inventory.

## Compatibility

- Overrides vanilla recipes in `data/minecraft/recipe/`. If another data pack changes the same recipes, **the one loaded last wins**.
- Targets 26.3 only. Other versions need their own release.

## How it compares

Older wood-recipe packs I found stop at earlier versions: *Better Wood* lists 1.12 to 1.20.3, and *More Trapdoors!* only changes trapdoors on 1.21 to 1.21.4. This pack targets the current 26.x line and covers the full wood set, Poplar included, with a stated rule behind every number.

## Building from source

The pack is generated by one script, so every number lives in a single table.

1. Edit the `YIELD` table at the top of `build_generous_wood.py`.
2. Run `python build_generous_wood.py` (Python 3, no dependencies).
3. The script writes `generous_wood.zip`. If a `pack.png` sits next to the script, it is added as the pack icon.

Every recipe file it generates overrides a vanilla recipe of the same name and keeps vanilla's pattern and ingredients. Only the result count changes.
